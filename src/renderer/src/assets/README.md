# Live Game Graphics

Champion, item, summoner spell, rune and profile images are resolved from Riot's
public Data Dragon catalogs. Metadata uses the English locale and is cached in
memory. Match images use an available Data Dragon build for that match's patch;
profile icons use the latest available build. Unknown patches and missing files
keep a neutral placeholder instead of showing unrelated artwork.

Data Dragon documentation:
https://developer.riotgames.com/docs/lol#data-dragon

Base URL: https://ddragon.leagueoflegends.com

Rank emblems are bundled locally; their source is documented in ranks/README.md.
All game artwork belongs to Riot Games.
